# ytdl

> 🇺🇸 [English](./README.md) | 🇯🇵 [日本語](./README.ja.md) | 🇨🇳 [简体中文](./README.zh-Hans.md) | 🇪🇸 [Español](./README.es.md) | 🇮🇳 **हिन्दी** | 🇧🇷 [Português](./README.pt.md) | 🇮🇩 [Bahasa Indonesia](./README.id.md)

डेवलपर-उन्मुख सार्वभौमिक मीडिया डाउनलोड CLI। [yt-dlp](https://github.com/yt-dlp/yt-dlp) से वीडियो साइट्स, Torrent (P2P), RTMP/RTSP स्ट्रीम और अधिक से डाउनलोड करता है। इंटरैक्टिव UI + AI नेटिव (Claude Code प्लगइन)।

## अनुपालन और कानूनी सूचना

यह प्रोजेक्ट एक सामान्य मीडिया डाउनलोड टूल है।

यह केवल उस कंटेंट के लिए है जो:
- आपके अधिकार में है
- सार्वजनिक लाइसेंस (जैसे Creative Commons) के तहत है
- प्लेटफ़ॉर्म द्वारा डाउनलोड की स्पष्ट अनुमति है

कॉपीराइट कानूनों और प्रत्येक प्लेटफ़ॉर्म की सेवा शर्तों का पालन करना उपयोगकर्ता की जिम्मेदारी है। यह प्रोजेक्ट बिना अनुमति के कॉपीराइट सामग्री डाउनलोड करने को प्रोत्साहित या समर्थन **नहीं** करता।

## निषिद्ध उपयोग

- बिना अनुमति के कॉपीराइट सामग्री डाउनलोड करना
- बिना प्राधिकरण के सशुल्क या सदस्यता सामग्री डाउनलोड करना
- डाउनलोड किए गए मीडिया का पुनर्वितरण
- DRM या तकनीकी सुरक्षा उपायों को दरकिनार करना

## अनुमत उपयोग

- अपने द्वारा अपलोड किए गए कंटेंट का बैकअप
- अधिकार प्राप्त मीडिया का ऑफ़लाइन प्रोसेसिंग
- Creative Commons / पब्लिक डोमेन कंटेंट का आर्काइव
- उचित अधिकारों के साथ शैक्षिक और अनुसंधान उद्देश्य

## इंस्टॉल

```bash
npm install -g @kanketsu/ytdl
```

[yt-dlp](https://github.com/yt-dlp/yt-dlp) और [ffmpeg](https://ffmpeg.org/) आवश्यक हैं। पहली बार चलाने पर, यदि अनुपस्थित हैं तो ytdl स्वचालित इंस्टॉल का प्रस्ताव देगा। मैन्युअल इंस्टॉल:

```bash
brew install yt-dlp ffmpeg
```

### भाषा सेटिंग

डिफ़ॉल्ट UI भाषा जापानी है। हिंदी में बदलने के लिए:

```bash
# एनवायरनमेंट वेरिएबल
YTDL_LANG=hi ytdl

# CLI फ़्लैग
ytdl --lang hi "URL"
```

## उपयोग

### इंटरैक्टिव मोड

बिना आर्ग्यूमेंट चलाएँ — चरणबद्ध चयन:

```bash
ytdl
```

### कमांड मोड

```bash
# वीडियो साइट्स (yt-dlp, 1000+ साइट्स)
ytdl "https://example.com/watch?v=VIDEO_ID"        # सर्वश्रेष्ठ गुणवत्ता + थंबनेल + उपशीर्षक + विवरण
ytdl -a "https://example.com/watch?v=VIDEO_ID"     # केवल ऑडियो (m4a)
ytdl -q 720 "https://example.com/watch?v=VIDEO_ID" # 720p
ytdl -p "https://example.com/playlist?list=..."     # प्लेलिस्ट
ytdl -i "https://example.com/watch?v=VIDEO_ID"     # केवल जानकारी (डाउनलोड नहीं)

# Torrent / P2P
ytdl "magnet:?xt=urn:btih:..."                            # मैग्नेट लिंक (स्वतः पहचान)
ytdl "https://example.com/file.torrent"                   # .torrent URL (स्वतः पहचान)
ytdl "./file.torrent"                                     # स्थानीय .torrent फ़ाइल (स्वतः पहचान)

# RTMP / RTSP स्ट्रीम
ytdl "rtmp://live.example.com/stream/key"                 # RTMP लाइव स्ट्रीम
ytdl "rtsp://camera.example.com/feed"                     # RTSP कैमरा
ytdl --duration 60 "rtmp://..."                           # 60 सेकंड रिकॉर्ड

# साइट विश्लेषक (जब yt-dlp विफल हो)
ytdl --analyze "https://example.com/page-with-video"      # साइट विश्लेषण मोड बाध्य करें

# विशिष्ट बैकेंड बाध्य करें
ytdl --via torrent "magnet:?xt=..."
ytdl --via stream "rtmp://..."
ytdl --via ytdlp "https://..."

# yt-dlp को सीधे विकल्प पास करें
ytdl "URL" -- --limit-rate 1M
```

## विकल्प

| फ़्लैग | विवरण | डिफ़ॉल्ट |
|--------|--------|----------|
| `-a` | केवल ऑडियो (m4a) | off |
| `-q <रिज़ॉल्यूशन>` | गुणवत्ता (360/480/720/1080/1440/2160) | सर्वश्रेष्ठ |
| `-o <डायरेक्टरी>` | आउटपुट डायरेक्टरी | `~/Downloads` |
| `-p` | प्लेलिस्ट मोड | off |
| `-b <ब्राउज़र>` | कुकी ब्राउज़र | off |
| `-n` | कुकी के बिना (डिफ़ॉल्ट) | on |
| `-i` | केवल जानकारी | off |
| `-t` | डाउनलोड के बाद ट्रांसक्राइब | off |
| `--backend <b>` | ट्रांसक्रिप्शन बैकेंड (local/api) | local |
| `--manuscript <path>` | पांडुलिपि फ़ाइल पथ (सटीकता के लिए) | - |
| `--lang <code>` | भाषा (`ja`/`en`/`zh-Hans`/`es`/`hi`/`pt`/`id`) | `ja` |
| `--via <backend>` | बैकेंड निर्दिष्ट करें (ytdlp/torrent/stream/analyzer) | स्वतः |
| `--analyze` | साइट विश्लेषक मोड बाध्य करें | off |
| `--duration <सेकंड>` | स्ट्रीम रिकॉर्डिंग अवधि (सेकंड) | रोकने तक |
| `--` | yt-dlp को पास करें | - |

डिफ़ॉल्ट रूप से, ytdl ब्राउज़र कुकी का उपयोग नहीं करता। प्रतिबंधित कंटेंट (आयु सीमा, सदस्य-केवल आदि) के लिए `-b <ब्राउज़र>` का उपयोग करें।

## आर्किटेक्चर

ytdl URL के प्रकार के आधार पर स्वतः सही बैकेंड चुनता है:

```
ytdl CLI
  │
  ├── magnet: / .torrent  → Torrent बैकेंड (webtorrent P2P)
  ├── rtmp:// / rtsp://   → स्ट्रीम बैकेंड (ffmpeg spawn)
  ├── --analyze फ़्लैग    → साइट विश्लेषक बैकेंड (Chrome CDP)
  └── http(s)://          → yt-dlp बैकेंड (1000+ साइट्स)
                               └── विफलता पर → साइट विश्लेषक फ़ॉलबैक
```

yt-dlp बैकेंड `bin/ytdl.sh` (v1 से अपरिवर्तित) को रैप करता है। नए बैकेंड पूरी तरह `lib/backends/` में हैं।

## Claude Code प्लगइन

ytdl को Claude Code स्किल के रूप में उपयोग करें। Claude, AskUserQuestion के माध्यम से इंटरैक्टिव रूप से डाउनलोड विवरण की पुष्टि करेगा। वीडियो साइट्स, मैग्नेट लिंक, RTMP/RTSP स्ट्रीम और साइट विश्लेषण का समर्थन करता है।

### इंस्टॉल

```
/plugin marketplace add kanketsu-jp/ytdl
/plugin install ytdl@kanketsu-ytdl
```

### उपयोग

Claude Code की बातचीत में कोई भी मीडिया URL (वीडियो साइट, मैग्नेट लिंक, स्ट्रीम URL) पेस्ट करें या "यह डाउनलोड करो" कहें। स्किल स्वचालित रूप से सक्रिय होता है:

1. जाँचता है कि `ytdl` इंस्टॉल है (नहीं है तो इंस्टॉल का प्रस्ताव)
2. URL प्रकार पहचानता है और उचित बैकेंड चुनता है
3. मीडिया जानकारी प्राप्त करता है (जब लागू हो)
4. पूछता है क्या चाहिए (वीडियो/ऑडियो, गुणवत्ता, सेव लोकेशन)
5. डाउनलोड करता है

## AI सुविधाएँ

### सार्वभौमिक URL पहचान

कोई भी URL पेस्ट करें — ytdl स्वतः सही बैकेंड पर रूट करता है:
- वीडियो साइट्स (1000+ समर्थित) → yt-dlp
- `magnet:` लिंक → Torrent (webtorrent)
- `.torrent` फ़ाइल (स्थानीय या URL) → Torrent (webtorrent)
- `rtmp://`, `rtsp://` → स्ट्रीम कैप्चर (ffmpeg)
- एम्बेडेड वीडियो वाला पेज → साइट विश्लेषक

### पेज URL विश्लेषण

आपको वीडियो का सीधा URL खोजने की ज़रूरत नहीं। बस उस पेज का URL पेस्ट करें जहाँ वीडियो एम्बेडेड है, और AI:

1. पेज का विश्लेषण करके एम्बेडेड वीडियो खोजेगा
2. मिले वीडियो दिखाएगा (अगर कई हैं तो चुनने देगा)
3. चयनित वीडियो डाउनलोड करेगा

Claude Code के साथ काम करता है।

**उदाहरण:**
```
https://example.com/blog/my-post से वीडियो सेव करो
```

### बैच डाउनलोड

एक साथ कई URL पेस्ट करें। AI आपकी प्राथमिकताएँ (वीडियो/ऑडियो, गुणवत्ता) सिर्फ एक बार पूछेगा और सभी डाउनलोड पर लागू करेगा।

**उदाहरण:**
```
ये डाउनलोड करो:
https://example.com/watch?v=aaa
https://example.com/watch?v=bbb
magnet:?xt=urn:btih:ccc
```
